================================================================================
OVERVIEW
================================================================================

A Claude Code-built cold outbound system that processed 55,000 prospects,
with every email personalized to what that business is actually doing.

================================================================================
THE PIPELINE
================================================================================

1. CSV UPLOAD
   - Drop up to 150,000 prospect rows into the web app (Cold Outbound > Upload)

2. DOMAIN VALIDATION
   - Validates domains through Hunter

3. WEBSITE SCRAPING
   - Scrapes each prospect's site for products and positioning

4. META ADS CHECK
   - Hits the Meta Ads Library to see if they're running ads
   - If yes, pulls the actual creative

5. AI STRATEGY ANALYSIS
   - Claude + Gemini analyze their ad strategy

6. ICP SCORING
   - Scores each prospect against the Ideal Customer Profile

7. TOP 20% — AI-GENERATED SAMPLE ADS
   - AI-generated ads made specifically for their brand
   - Uses Nano Banana 2 (Gemini image model)

8. PERSONALIZED EMAIL DELIVERY
   - Everyone gets a personalized email via Instantly
   - References what they're actually running

================================================================================
COST
================================================================================

$0.16 per prospect for the full pipeline

================================================================================
TECH STACK
================================================================================

- Claude Code (pipeline orchestration)
- Hunter (domain validation)
- Meta Ads Library (ad creative pull)
- Claude + Gemini (strategy analysis)
- Nano Banana 2 / Gemini (AI ad image generation)
- Instantly (email delivery)
- Apollo, Kitt, LeadMagic, IcyPeas, Pattern (email enrichment waterfall)
